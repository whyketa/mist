# MIST

Синтезатор, который притворяется увлажнителем воздуха. На столе стоят прибор и пульт. Пульт управляет тремя голосами: каплями воды, колокольчиками и шумом пара. Прибор отвечает паром, светом и огоньками.

**Сайт:** https://whyketa.github.io/mist/

## Управление

Нажмите на пульт на столе, чтобы взять его в руку. Esc или клик мимо пульта кладёт его обратно.

| Кнопка | Действие |
| --- | --- |
| синие + / − | громкость воды (WATER) |
| зелёные + / − | громкость колокольчиков (BELL) |
| оранжевые + / − | громкость пара (MIST) |
| солнце | режим воды: CALM → FLOW → RAIN → RANDOM |
| луна | режим колокольчиков: TEMPLE → ZEN → NIGHT → RANDOM, NIGHT гасит свет |
| волны | общий темп: 40 → 52 → 70 → 100 BPM |
| крышка | открывает экран и четыре ползунка |

Ползунки под крышкой меняют звук голоса, которого коснулись последним: фильтр, реверберацию, панораму и эхо.

## Структура

```
index.html        сцена и пульт
css/style.css     оформление
js/sound.js       голоса, эффекты и общий транспорт (Tone.js)
js/remote.js      пульт, экран, огоньки, лампа
js/steam.js       пар на canvas
img/              прибор и пульт
```

## Запуск

Откройте сайт по ссылке выше или запустите любой локальный сервер в папке проекта, например `npx serve`. Звук включается после первого нажатия.

Сделано на [Tone.js](https://tonejs.github.io/).
